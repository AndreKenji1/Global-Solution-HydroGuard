# Evidências de execução

O repositório inclui o resumo JSON dos 102 testes e a inspeção sanitizada do contêiner Docker. As capturas em ../imagens/ usam apenas dados sintéticos. Logs brutos, credenciais, cookies, bancos e fotografias operacionais ficam fora do Git. Resultados, comandos e limitações estão em ../relatorio-validacao.md.
